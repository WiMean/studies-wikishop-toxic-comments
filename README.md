# Классификация токсичных комментариев для «Викишоп» (NLP)

**Задача.** Интернет-магазин запускает сервис с правками описаний товаров. Нужен инструмент, который находит токсичные комментарии и отправляет их на модерацию. Требуемое качество — F1 не ниже 0,75.

**Что сделано.** Очистка и лемматизация текста, TF-IDF и логистическая регрессия, LightGBM, дообучение BERT (transformers, PyTorch), сравнение подходов и выбор лучшей модели.

**Стек.** Python, pandas, scikit-learn, LightGBM, PyTorch, transformers, nltk, spaCy

**Результат.** F1 0,77 при пороге 0,75; accuracy до 0,98 на сбалансированной выборке
